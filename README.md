# EvidenceLab
A program for students to analyze and understand their data in one place, with trends, regressions, and experimental limitations.

Main Analysis Modes:

Relationship and Correlation Analysis - Analyses how two numerical variables relate to eachother (Scatter plots, trendlines, correlation coefficients, regression equations, and interpretation of relationships)

Comparative Analysis - Compares measurements between variable groups (Group averages, differences, standard deviations, bar charts)

Time-Series Analysis - Analyses how a variable changes over time (Time-series graphs, rates of change, trends, anomalies, and possible patterns over time.)
